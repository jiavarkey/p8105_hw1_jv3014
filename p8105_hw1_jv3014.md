Calculating the mean works for the random sample and logical vector. It
does not work for the character or factor vector since it is not
numeric.

``` r
num_log = as.numeric(pull(data,log_var))
num_char = as.numeric(pull(data,char_var))
num_factor = as.numeric(pull(data,factor_var))
```

The logical vector returns numeric 0s and 1s, the character and factor
vector return NA only. This explains what happens when you try to take
the mean of each variable because it cannot be calculated on non-numeric
variables.
